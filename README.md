# 🩺 Kidney Stone, Cyst, Tumor Detection using CNN and Transfer Learning

## 📌 Project Overview
This project is a deep learning-based web application that detects kidney conditions such as Cyst, Tumor, Stone, and Normal from CT scan images.

It uses CNN (Convolutional Neural Network) and Transfer Learning (InceptionV3) to improve accuracy and automate medical image classification.

---

## 🎯 Objective
To help in early detection of kidney diseases using Artificial Intelligence and improve accuracy and speed of diagnosis.

---

## 🚀 How It Works
1. CT scan images are collected and preprocessed.
2. CNN / InceptionV3 model is trained on labeled kidney images.
3. The model learns patterns for:
   - Cyst
   - Tumor
   - Stone
   - Normal
4. Flask web application allows users to upload images.
5. Model predicts the kidney condition.
